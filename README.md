# Student Attendance Management System

A simple web-based Student Attendance Management System built using HTML, CSS, and JavaScript.

## Live Demo

[Click here to view the project](https://github.com/lokkuntlaakhila/student-attendence-management-system.git)

## Features

- Add new students
- Automatically assign roll numbers
- Mark students as Present or Absent
- Select attendance by date
- Calculate attendance percentage
- Delete students
- Store student data using browser Local Storage
- View attendance records for different dates

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
